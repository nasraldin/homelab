# Platform audit — 2026-10-25

Deep audit of the live lab (Proxmox host, Talos cluster, GitLab CI) and the
active repos. What was changed, what is waiting for review, and what is left.

| Signal                | Value                                                                |

## Done live

- etcd snapshot (kept in `~/homelab-backups/etcd/`, 0600) and defrag: 129 → 39 MB.
- Control plane consolidated to **one node** (`talos-cp01`, 4 vCPU / 6 GiB,
  CPU weight 2048). cp01 was resized while three members still held quorum
  (zero API downtime); cp03 then cp02 left etcd cleanly and were powered off.
  One ~60 s API gap occurred while the VIP moved from cp02 to cp01.
- Kubelet `kubeReserved`/`systemReserved` + hard/soft memory eviction on all
  workers (no reboot); second NTP server on all nodes; etcd metrics on `:2381`.
- Workspace: retired repos moved to `archive/`; duplicate
  `platform-services-safe-patches` worktree removed.

After: host 73.4 GiB used, load ~9 → ~6; API p99 POST 0.09 s, LIST 0.20 s;
apiserver memory stall 0; cp01 57% memory available.

## Rollout — 2026-10-27

All MRs above are merged and applied through their pipelines.

- cluster-infra: `terraform:provision` destroyed VMs 302/303 only (plan: 0 add,
  0 change, 2 destroy). The `talos:apply-config-dry-run` output matched the live
  config on all 6 nodes with no reboot. `cluster:verify` passed. The first encrypted
  `etcd:backup` (`etcd-snapshots/2026.10.27-1610`, 37 MB) is in the package

  deployed with its script because it has no CI job. Follow-up MRs merged while
  rolling out:
  - !108: cache-authority allowlists now hold the current and previous SHA
    (templates `1d9eb28b`, coordinator `4955de0`). `envoy-gateway:deploy` no
    longer waits on a Cilium redeploy.
  - !109–!112: fixed verify scripts that gave false failures. lab-dns
    expected VM IPs. cnpg counted terminated pods. artifacts restarted the
    retired `harbor-database`. Four scripts still assumed 7 nodes.

  `domain-migration` field manager from 29 HTTPRoutes and stale `kubectl-patch`

  conflicting with them. Deleted 12 dead `Succeeded` ReplicaSet pods left by node
  shutdowns.

## Roadmap (recommended order)

**P1**

- Extend the Harbor proxy cache (docker.io is done, 2026-10-31) to ghcr.io,
  quay.io and registry.k8s.io, with the same Talos mirror + fallback pattern.
- Protect remaining unprotected CI secrets (platform-services `KUBECONFIG_FILE`,
  pipeline-templates `GITLAB_TOKEN`, ajrly-platform-ci tokens); protect `main`
  on ajrly-platform-ci; enable "pipelines must succeed" on all projects.
- Secrets: create Kubernetes Secrets from Infisical (`InfisicalSecret`, the
  operator is already installed with zero CRs) instead of 27 imperative scripts;
  stop mirroring 82 Infisical keys into GitLab variables.
- ajrly-postgres: 2 instances, `dataDurability: preferred`, smaller requests
  (real use ~200 Mi per instance); re-budget pooler connections.
- Default-deny NetworkPolicies for aistor, cloudflare-system, cnpg-system,
  envoy-gateway-system, cert-manager.
- Single owner for ZFS ARC (`proxmox-bootstrap` defaults to 16 GiB and would
  double it if re-run; `lab-home-pve01` sets 8 GiB).
- Move vzdump off 02:00 (collides with Barman backups).

**P2**

- pipeline-templates → CI/CD Catalog components with `spec:inputs`, tagged
  releases; consumers pin versions (see `pipeline-templates/docs/roadmap-components.md`).
- platform-services: one `ci-tools` image as default CI image, one deploy
  library instead of 20 copy-pasted deploy scripts, tests under `tests/`;
  move AI apps and Ajrly CI glue to `ajrly-k8s-deployments`.
- BuildKit registry cache to Harbor for image builds.
- GitLab Omnibus tuning (puma memory cap, Postgres shared_buffers, gitaly
  cgroups, KAS off) then shrink gitlab-01 12 → 8 GiB.
- Finish domain migration leftovers (`ajrly.com`, `nasraldin.com`, `*.lab`).
- vTPM + Talos STATE/EPHEMERAL disk encryption; break-glass age recipient.
- Disk cache `writethrough` → `none` on Talos VMs (maintenance window; the
  Terraform disk block is `ignore_changes`).
