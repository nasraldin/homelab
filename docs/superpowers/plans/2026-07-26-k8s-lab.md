# k8s-lab HA kubeadm + homelab-gitops Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create sibling repos `k8s-lab` (Terraform VMs + Ansible kubeadm HA + bootstrap scripts + docs) and `homelab-gitops` (Argo CD app-of-apps) for a 3 CP + 3 worker Kubernetes lab with HAProxy, Cilium Gateway API, Istio mesh, and in-cluster observability.

**Architecture:** Layered bootstrap — `k8s-lab/terraform` owns seven Proxmox VMs (own state); Ansible installs containerd, kubeadm HA behind HAProxy, labels, and etcd backups; one-shot scripts install Cilium (CNI + LB IPAM + L2 + Gateway API) and Argo CD; `homelab-gitops` owns day-2 platform charts. Hub `homelab` only wires `repos.json` and curriculum links.

**Tech Stack:** Terraform (bpg/proxmox), Ansible, Debian 13, containerd, kubeadm 1.36.x (`pkgs.k8s.io`), HAProxy, Cilium, Argo CD, Helm, cert-manager, Kyverno, Longhorn, Istio, kube-prometheus-stack, Loki, Tempo

## Global Constraints

- Kubernetes **1.36.x** latest patch from **`pkgs.k8s.io`** only (no deprecated apt.kubernetes.io).
- Topology: `haproxy-01` + `k8s-cp-01..03` + `k8s-w-01..03` (stacked etcd).
- Sizing (resizable later): HAProxy 1c/1G/20G; CP 2c/4G/40G; workers 4c/8G/60G OS + ~50G data disk.
- Example LAN: `.40` HAProxy, `.41–.43` CP, `.44–.46` workers; Cilium LB pool `192.168.68.100–119`.
- API endpoint: `kube-api.lab.nasraldin.com:6443` → HAProxy TCP.
- Cilium owns north-south (Gateway API + LB IPAM + L2); Istio owns east-west only.
- Observability in-cluster via GitOps; do not replace `monitoring-01` for non-k8s.
- After Argo CD exists, do **not** Helm-install platform apps from Ansible.
- Talos: docs comparison only (no VMs).
- Secrets stay gitignored (`*.auto.tfvars`, `secrets.yml`, kubeconfigs).
- Reuse Proxmox cloud image already imported by `terraform-lab` when possible (do not fight that state).
- Follow existing lab style: Debian user `nasr`, bridge `vmbr0`, datastore `data01`, gateway `192.168.68.1`, CIDR `/22`.

```hcl
  description = "Optional second disk (scsi1) for Longhorn; null = none"
  type        = number
  default     = null
}
```

In `main.tf`, after the OS `disk` block:

```hcl
dynamic "disk" {
  for_each = var.data_disk_gb != null ? [var.data_disk_gb] : []
  content {
    datastore_id = var.datastore_id
    interface    = "scsi1"
    iothread     = true
    discard      = "on"
    ssd          = true
    cache        = "none"
    size         = disk.value
    file_format  = "raw"
  }
}
```
