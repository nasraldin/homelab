# Status symbols

Shared legend for status tables across these docs. Use the same symbols in the
roadmap, current-state board, and install pages so one emoji means one thing
everywhere.

When something moves from “ready in Git” to “live on the node,” update the
relevant roadmap or operations page in the **same** change.

## What this page covers

- Done vs ready-in-Git vs in progress
- Pending, deferred, and future
- When to update status after an apply

| Symbol | Meaning                                                              |
| ------ | -------------------------------------------------------------------- |
| ✅     | **Done** — live on the node or in daily use                          |
| 🟡     | **Ready** — implemented in Git; still need apply/install on the node |
| 🔄     | **In progress** — started but not finished                           |
| ⏳     | **Pending** — not started                                            |
| ⏸️     | **Deferred** — intentional hold (with a written reason)              |
| 🔮     | **Future** — blocked on hardware or a later phase                    |
